Como Inserir sua Assinatura

🚀 Atalho Rápido para a Pasta de Assinaturas

O Windows armazena as assinaturas do aplicativo Outlook na pasta oficial de assinaturas. Escolha uma das opções abaixo:

Opção 1: Copiar Caminho da Pasta
%APPDATA%\Microsoft\Signatures

💡 Pressione Win + R no teclado, cole o caminho e aperte Enter.

Opção 2: Baixar Atalho Direto

Baixe um atalho automático que abre a pasta no Windows Explorer com 1 clique:

📋 Passo a Passo pelo Menu do Outlook Desktop:

  1. Copie a assinatura gerada usando o botão "Copiar Assinatura Formatada".
  2. Abra o aplicativo Outlook no seu computador.
  3. Clique em Arquivo → Opções → Email.
  4. Clique no botão Assinaturas....
  5. Clique em Novo, digite um nome (ex: Machado de Assis).
  6. Na caixa de edição de texto abaixo, pressione Ctrl + V para colar a assinatura.
  7. Em "Escolher assinatura padrão", selecione a nova assinatura para Novas mensagens e Respostas/encaminhamentos.
  8. Clique em OK para salvar!

🌐 Passo a Passo para Outlook Web (Navegador)

  1. Copie a assinatura gerada clicando em "Copiar Assinatura Formatada".
  2. Clique no botão "Inserir no Outlook Web" para abrir diretamente a tela de assinaturas.
  3. Na página que se abre, clique em "+ Nova assinatura".
  4. Dê um nome para a assinatura (ex: Institucional Machado de Assis).
  5. Clique no campo de edição e pressione Ctrl + V para colar a assinatura formatada.
  6. Em "Selecionar assinaturas padrão", defina a nova assinatura para Para novas mensagens e Para respostas/encaminhamentos.
  7. Clique em Salvar no canto inferior direito. Pronto!
